交通

全程自駕，起訖點皆為基督城（CHC）。路線順時針：基督城 → 霍基蒂卡 → 法蘭茲約瑟夫冰川 → 瓦納卡 → 皇后鎮 → 蒂卡波湖 → 基督城。 租車建議： - 選擇附雪鏈或 AWD／4WD 車款，或確認保險條款涵蓋雪地事故。 - 主要幹道為 SH6（西岸）、SH8（內陸）；哈斯特隘口（Haast Pass）段彎道多，預留充裕時間。 - 加油站在西岸及偏遠路段間距可達 80–100 km，每日出發前確認油量。 - 皇后鎮停車費用較高，建議住宿時確認含停車位。

天氣

六月為紐西蘭南島冬季，各地氣候差異顯著： - 基督城：日均 3–12°C，晴天居多，偶有霜凍。 - 西岸（霍基蒂卡、法蘭茲約瑟夫）：多雨潮濕，年降雨量超過 3,000 mm，冰川區可能全天雲霧，影響直升機行程。 - 哈斯特隘口：風強，積雪時路況惡劣。 - 瓦納卡／皇后鎮：乾冷，山區積雪明顯，夜間可低至 -5°C 以下。 - 蒂卡波湖：高原地形，夜晚寒冷，日夜溫差大，但晴夜能見度佳，適合觀星。 冰川直升機高度依賴天氣，建議行程預留彈性天或備案活動。

冬季自駕注意

冬季南島自駕風險集中於山區積雪與結冰路段，需提前準備： 1. 雪鏈／雪胎：NZTA 可強制要求車輛裝備雪鏈才能通行，租車時確認是否附帶並學習裝卸方法。 2. 路況查詢：出發前查閱 NZTA Journey Planner（journeys.nzta.govt.nz）及 MetService 山區預報。 3. 駕駛技巧：南島山路多急彎、陡坡、單線橋（give way to oncoming），夜間避免趕路。 4. 緊急應變：備妥車內保暖毯、手電筒、乾糧；西岸部分路段手機訊號弱，下載離線地圖（如 Maps.me 或 Google Maps 離線包）。 5. 預訂彈性：冰川直升機健行（約 TWD 10,000/人）建議預訂兩個可改期時段，天候取消率高。 6. 保險：確認信用卡或租車附加險涵蓋雪地／冰面事故，避免自付超額（excess）過高。
